Nothing came out this week worth writing about. The labs took the holiday off. So did most of my team. I am using the space to write down what I actually learned this year.

## Chains to agents

In January I was still writing LangChain chains. By December every new system I designed was a set of agents with an orchestrator. The change was not about the framework. The change was that I stopped deciding the control flow up front. I give each agent a narrow job and a set of tools, and I let the orchestrator route. The Scout system for Let's Forage was the first project where I did this from day one. Nine agents. One root. It was harder to test and easier to extend.

## Evals moved to the front

At Developers Inc I built the medical claims pipeline and added evaluation late. We caught problems after they reached the payer. At Zazmic I put an eval harness in before the first agent existed. Every prompt change runs against a fixed set of cases in CI. That single habit saved more client trust than any model upgrade.

## Tool contracts matter more than prompts

Most of my debugging time this year went into tool interfaces, not prompts. A tool that returns inconsistent shapes breaks an agent in ways that no prompt can fix. I now write the tool schema first and the prompt second.

## What is next

January starts the migration track. A client wants a decade of stored procedures moved to BigQuery. I plan to do it with agents that translate, validate, and document, with a human approving each batch. I expect the validation agent to be the hard part. The translation is the easy part. I will write about it as it happens.
