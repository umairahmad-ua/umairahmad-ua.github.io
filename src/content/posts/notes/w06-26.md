Thursday was the busiest release day since November.

## What happened

- OpenAI put out a [Codex desktop app](https://openai.com/index/introducing-the-codex-app/) for macOS on Monday.
- Anthropic released [Claude Opus 4.6](https://www.anthropic.com/news/claude-opus-4-6) on Thursday, with a 1M context beta and a research preview of agent teams in Claude Code.
- OpenAI released [GPT-5.3-Codex](https://openai.com/index/introducing-gpt-5-3-codex/) the same day.
- OpenAI also announced [Frontier](https://openai.com/index/introducing-openai-frontier/), an enterprise agent platform.

## What I make of it

Two things stand out. The first is agent teams in Claude Code. I have been running multi-agent systems for clients since last summer. Now the coding tool I use to build them is itself a multi-agent system. My team tried it on the migration codebase on Friday. One agent wrote the validation change, another reviewed it, a third ran the tests. It worked. It also used a lot of tokens. I will keep it for large refactors and turn it off for daily work.
