Anthropic spent the week removing names. On Tuesday [Cowork became Claude](https://claude.com/blog/cowork-is-now-claude), with Docs and Slides arriving as betas inside the same app. On Wednesday [Claude Code Projects](https://claude.com/blog/projects-redesigned) got a coordinator that runs parallel cloud sessions. On Thursday Claude Code [learned to read AGENTS.md](https://forums.theregister.com/forum/all/2026/09/18/202619/) when there is no CLAUDE.md.

## Fewer surfaces, same questions

For a team building client agents, the consolidation matters more than the new features. Every client I work with has asked some version of "which Claude do we buy". Last month the answer had four parts. This week it has one app and one developer surface. That is easier to put in a proposal. It is also easier to govern, because the admin controls now cover one thing.

The Docs and Slides betas are not what I will use first. The coordinator in Projects is. We run migration validation as a long job with several independent checks. A coordinator that fans those out to cloud sessions and reports back is the shape we built by hand in April.

## The small one

The AGENTS.md change is a footnote in the release notes. It landed the same week I moved this site's own working guide from CLAUDE.md to AGENTS.md, with a symlink for the old name. One file that any coding agent reads is a better contract than one file per vendor. I had already made the bet. Thursday made it cheaper.
