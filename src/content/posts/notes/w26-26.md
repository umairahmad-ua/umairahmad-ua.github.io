Not every week has a frontier release. This one did not. I used the room to close out a migration batch and to sit with the supply-chain planners in Jordan for two days of calls.

What happened:

- Anthropic launched [Claude Tag, Claude inside Slack](https://github.com/jqueryscript/anthropic-claude-timeline). You mention it in a channel and it answers with the channel as context.
- Claude Code added [`claude mcp login`](https://code.claude.com/docs/en/whats-new/2026-w26). OAuth for MCP servers is now one command instead of a config file and a pasted token.
- OpenAI opened [GPT-5.6 to a limited set of trusted partners](https://en.wikipedia.org/wiki/GPT-5.6). No public access. No public benchmarks worth trusting yet.
