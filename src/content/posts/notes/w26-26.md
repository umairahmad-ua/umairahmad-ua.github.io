Not every week has a frontier release. This one did not. I used the room to close out a migration batch and to sit with the supply-chain planners in Jordan for two days of calls.

What happened:

- Anthropic launched [Claude Tag, Claude inside Slack](https://github.com/jqueryscript/anthropic-claude-timeline). You mention it in a channel and it answers with the channel as context.
- Claude Code added [`claude mcp login`](https://code.claude.com/docs/en/whats-new/2026-w26). OAuth for MCP servers is now one command instead of a config file and a pasted token.
- OpenAI opened [GPT-5.6 to a limited set of trusted partners](https://en.wikipedia.org/wiki/GPT-5.6). No public access. No public benchmarks worth trusting yet.

## What I make of it

The MCP login command is the one that matters for my team. Auth was the reason half our MCP servers stayed on a laptop and never reached a shared environment. A token in a JSON file is not something I can hand to a client's security team. An OAuth flow is. Our cloud operations agent talks to Cloud Monitoring and to the ticketing system through MCP. Both connectors move to the login flow next sprint.

Claude in Slack is interesting for a different reason. Most of the questions our clients ask their data are asked in a chat channel first. Scout started as a chat surface for exactly that reason. If the model can sit where the question is asked, the retrieval problem gets easier. The context is already in the thread.

On GPT-5.6, I have nothing to say until I can run it against our eval set. A partner-only preview is a press release, not a model.

## The planners

Two days with the planning team taught me more than the release notes. They do not want the agent to plan. They want it to explain why last week's plan went wrong. That is a different product. We are adjusting the orchestrator so the first thing it does each Monday is a variance report, in their words, not ours.
