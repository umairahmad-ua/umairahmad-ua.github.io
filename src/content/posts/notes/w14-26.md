## What happened

- AWS made [AgentCore Evaluations generally available](https://aws.amazon.com/about-aws/whats-new/2026/03/agentcore-evaluations-generally-available) on Tuesday. Evaluation of agent runs is now a managed service on Bedrock, not a script you maintain.
- Claude Code moved [computer use into the CLI](https://code.claude.com/docs/en/whats-new/2026-w14) as a research preview. The agent can now drive a browser or a desktop app from the terminal.
- [Cursor 3](https://cursor.com/blog/cursor-3) added an Agents Window, a view for running several coding agents at once.
