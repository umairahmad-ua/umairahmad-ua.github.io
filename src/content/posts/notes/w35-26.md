## Memory with a control panel

Claude's memory now [works across chat and Cowork, and the user decides what is in it](https://claude.com/blog/claudes-memory-works-everywhere-and-you-decide-whats-in-it). The second half of that sentence is the product.

Agent memory has been the hardest design conversation with every client this year. Not the storage. The governance. Who can see what the agent remembers about a customer. Who can delete it. What happens when a planner leaves the company and the agent still holds her preferences. For Scout we built a memory store with an owner field and an expiry on every entry. It took two sprints. It should have been a platform feature. Now, at least for the consumer product, it is. I expect the enterprise API to follow and I will move our store onto it when it does.
