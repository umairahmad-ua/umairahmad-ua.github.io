Monday was busy. Anthropic released [Claude Sonnet 4.5](https://www.anthropic.com/news/claude-sonnet-4-5) and Claude Code 2.0 on the same day. Sonnet 4.5 is pitched as the best model for long agentic tasks. I ran it against our Scout eval set on Tuesday. It was better on multi-step tool use. It was not better on short extraction. The eval told me that in an hour. The launch post could not.

## The rename matters

The Claude Code SDK is now the [Claude Agent SDK](https://www.anthropic.com/news/enabling-claude-code-to-work-more-autonomously). That is a small change in naming and a large change in intent. Anthropic is saying the harness that runs Claude Code is a general agent runtime, not a coding tool. I agree with the framing. The loop of read context, call tools, check results, and repeat is the same whether the tools are a file system or a BigQuery client.

For our team this means one more serious option next to Google ADK. I do not plan to switch. I do plan to keep the tool layer portable so we could.
