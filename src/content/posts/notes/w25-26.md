This week marks one year since I joined Zazmic. I spent most of it in review meetings, not in code. That felt wrong and right at the same time. The team is eight people now. The systems we run did not exist twelve months ago.

## The harness is the product now

AWS made [Bedrock AgentCore Harness generally available](https://aws.amazon.com/about-aws/whats-new/2026/06/amazon-bedrock-agentcore-harness-generally-available/) on Tuesday. A year ago the harness was the part every team wrote themselves. The loop, the retries, the tool dispatch, the trace. Now three clouds sell it as a managed service. I think this is the right direction. Most of the harness code I have reviewed in client repos was the same code with different bugs.

The part that does not get managed away is the tool contract. What the agent is allowed to call, with what arguments, under which approval. That is still our work. It will stay our work.

## Work IQ and the data question

Microsoft moved [Work IQ APIs to GA](https://medium.com/@adnanmasood/microsoft-build-2026-recap-578eabee16c2) the day before. Every platform now wants to be the memory layer for enterprise agents. I understand why. Whoever holds the context holds the customer. For our clients on Google Cloud this is not a decision yet. For our clients with Microsoft 365 estates it will be by autumn.
