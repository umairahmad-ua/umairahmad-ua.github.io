In week 25 I wrote that the harness had become the product. This week OpenAI made it an API call.

## The Agents API

OpenAI opened the [Agents API in public beta](https://www.marktechpost.com/2026/09/10/openai-launches-the-agents-api-in-public-beta-putting-the-codex-harness-behind-one-api-call/) on Thursday. You send a task and a set of tools. The Codex harness runs the loop on their side and returns the result. No orchestration code on yours.

I understand the appeal. Most of the harness code in the world is the same loop with different bugs. But I build for clients who need to know what happened between the request and the result. Which tool was called, with what arguments, approved by whom. A hosted harness gives me a result and a trace. It does not give me a place to put a policy check between two steps. Google's Agent Platform and Bedrock's AgentCore have the same tension. Every managed harness trades control for convenience. For a marketing assistant that trade is fine. For an agent that writes to a bank's data warehouse it is not, and no beta label changes that.

## A Data agent

OpenAI also released a [Data agent inside ChatGPT Work](https://aiagentstore.ai/ai-agent-news/this-week). It answers questions over your connected data. This is the product Scout was two years ago, from a company with a billion users. I am not worried. Scout's value was never the chat. It was the nine agents that know what a campaign brief looks like for a specific client. A general data agent does not know that. It cannot. The moat in enterprise agents is the domain, not the model.

## Plugin evals

Claude Code added [`claude plugin eval`](https://code.claude.com/docs/en/whats-new/2026-w37). You write an eval suite for a plugin and run it in CI. My team maintains four internal plugins. None had tests beyond "it ran once on my machine." That changes this sprint. An eval on a plugin is the same discipline as an eval on an agent. If it is not measured it is not done.

DeepSeek released [V4.1-Flash](https://local-ai-zone.github.io/blog/September_2026_AI_Model_Updates.html) the same day. Noted. Not tested.

## Looking at the year

This is the fifty-second weekly note. A year ago the questions were which framework and which model. This week the questions are which harness, whose policy layer, and where the trace lives. The field moved from building agents to governing them. So did my job.
