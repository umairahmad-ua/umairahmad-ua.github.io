I spent two years building on LangChain at Developers Inc. This week it reached [1.0](https://changelog.langchain.com/announcements/langchain-1-0-now-generally-available), together with LangGraph. It is strange to see a stable release for a library that changed under my feet every month in 2024. Stability is the feature. A 1.0 means the team can commit to an API for a year without a rewrite.

I do not use LangGraph for our Google Cloud agents. ADK fits the platform better. But the graph model that LangGraph made popular is now the default way everyone thinks about agent control flow. Nodes, edges, checkpoints, human approval as a node. That mental model won.

## Browsers as agent surfaces

OpenAI launched [ChatGPT Atlas](https://openai.com/index/introducing-chatgpt-atlas/), a browser with the assistant built in. The same week Anthropic put [Claude Code on the web](https://claude.com/blog/claude-code-on-the-web). Both moves put the agent where the work already happens instead of asking people to come to a chat box. For enterprise clients this is the right direction. Nobody wants another tab.
