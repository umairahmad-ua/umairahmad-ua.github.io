MCP no longer belongs to Anthropic. On Tuesday the Linux Foundation [formed the Agentic AI Foundation](https://www.linuxfoundation.org/press/linux-foundation-announces-the-formation-of-the-agentic-ai-foundation). Anthropic donated MCP to it. OpenAI contributed AGENTS.md, and Block brought its goose agent framework.

## Why this matters for the people I build for

Enterprise architects worry about betting on a protocol one vendor controls. I have had that exact conversation with a finance client twice this quarter. Neutral governance does not make the technology better. It makes the procurement conversation shorter. Since July our tool layer has been MCP-shaped. This week that decision stopped needing a defense.

There is a second effect. With OpenAI, Anthropic, and Block inside one foundation, the pieces are in place for the agent stack to standardize the way the container stack did. A shared tool protocol, a shared convention for repository instructions, a reference agent. It took Kubernetes about three years to go from donation to default. I expect this to be faster.

## Also this week

Mistral released [Devstral 2](https://mistral.ai/news/devstral-2-vibe-cli/) with a command-line agent called Vibe. Another open coding model, another CLI agent. OpenAI released [GPT-5.2](https://en.wikipedia.org/wiki/GPT-5.2) on Thursday. The release cadence is now roughly monthly for every frontier lab. My team stopped treating model releases as events. We treat them as a scheduled eval run. The harness pulls the new model, runs the suite, and posts a diff. If the diff is good, we move a canary. If not, nothing changes.
