Two tools my team uses every day changed this week.

## Claude Code stops asking

Claude Code added an [auto mode research preview](https://code.claude.com/docs/en/whats-new/2026-w13) plus computer use in the desktop app. Auto mode means the agent runs without the permission prompt on every step. I turned it on for one repo, the eval harness, and left it off for the migration agents. That split is deliberate. The eval repo has tests that catch mistakes in seconds. The migration code touches client SQL and needs a human between the plan and the commit. Auto mode is a trust setting, not a productivity setting. I told the team to treat it the way we treat approval gates in our own agents. Turn it off where the blast radius is large.
