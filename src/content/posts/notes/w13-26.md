Two tools my team uses every day changed this week.

## Claude Code stops asking

Claude Code added an [auto mode research preview](https://code.claude.com/docs/en/whats-new/2026-w13) plus computer use in the desktop app. Auto mode means the agent runs without the permission prompt on every step. I turned it on for one repo, the eval harness, and left it off for the migration agents. That split is deliberate. The eval repo has tests that catch mistakes in seconds. The migration code touches client SQL and needs a human between the plan and the commit. Auto mode is a trust setting, not a productivity setting. I told the team to treat it the way we treat approval gates in our own agents. Turn it off where the blast radius is large.

## ADK 2.0 comes into view

Google published a post on [why they built ADK 2.0](https://developers.googleblog.com/why-we-built-adk-20/). Graph-based workflows and agent teams are the headline. I have read it three times. Our Scout orchestrator at Let's Forage is a tree today. A root agent hands off to a sequential pair for data analysis and to six specialists for campaigns, personas, and strategy. A tree is easy to reason about and hard to make loop. Twice this year we wanted a critic agent to send work back to an author and had to fake it with a retry counter. Graph workflows solve that shape directly.

I am not moving Scout to an alpha. The client has Apple and Meta teams on the product. But I asked one engineer to rebuild the data analysis pair on the preview and report back on two things. How the graph handles a cycle that never converges, and what the trace looks like in Agent Engine. If the trace is readable, the migration is worth it. If it is not, we wait.
