The [MCP 2026-07-28 specification](https://blog.modelcontextprotocol.io/posts/2026-07-28/) is final. The release candidate came out in May, so nothing here is a surprise. That does not make it less work.

## What changed

The core is stateless now. Tasks and Apps moved to extensions. Roots, Sampling and Logging are deprecated. A server written against the November 2025 spec still runs, but the parts we leaned on are on a clock.

We have eleven MCP servers in use across client work. Two of them used Sampling to let the server ask the model a question mid-tool-call. That pattern is gone. I spent Wednesday and Thursday rewriting both. The replacement is plainer. The server returns structured data and the agent decides what to ask next. In hindsight the old design let the tool think, and tools should not think. Tools should return facts.

The stateless core is good news for anyone deploying on Cloud Run. Session affinity was the reason two of our servers needed a sticky load balancer. That requirement is gone.
