This was the busiest week of the year so far. Four items, one opinion each.

## Mythos and Glasswing

Anthropic announced a [Claude Mythos Preview](https://www.anthropic.com/glasswing) and a program called Project Glasswing. The model sits above Opus and is restricted to security partners for now. The stated reason is that it finds software vulnerabilities too well to release openly. I worked on Ocular and Autofix at Qwiet AI. Ocular scored source-to-sink paths on code property graphs with a graph neural network. It was good and it was narrow. A general model that finds flaws better than a purpose-built system is a different thing. I believe the restriction is sincere. I also expect the capability to be table stakes within a year.

## Managed Agents

[Claude Managed Agents](https://claude.com/blog/claude-managed-agents) went into public beta. Anthropic hosts the loop, the sandbox, and the state. This is the same shape as Agent Engine on Google Cloud, which is where our Scout agents live. The bet is identical. Teams do not want to run the harness. I agree with the bet and I still run one harness myself, the cloud operations agent on Claude, because the permission model is the product and I do not trust a default to get it right for infrastructure.

## Meta moves on from Llama

[Muse Spark](https://about.fb.com/news/2026/04/introducing-muse-spark-meta-superintelligence-labs/) is Meta's new flagship and it replaces Llama inside Meta AI. Two years ago I fine-tuned Llama 2 with QLoRA for a client at Developers Inc. Llama was the default open weight for a long time. It is not the default anymore. The open-weight center of gravity moved to Qwen, DeepSeek, and Kimi, and this week made it official.

## A2A turns one

Google marked [a year of A2A](https://opensource.googleblog.com/2026/04/a-year-of-open-collaboration-celebrating-the-anniversary-of-a2a.html) and gave 1.0 its public moment. We use A2A for exactly one thing, letting the supply-chain planning agents call a client's existing procurement agent. It works. I have no other use for it yet. Most of our agent-to-agent traffic stays inside one ADK process, where a protocol is overhead.
