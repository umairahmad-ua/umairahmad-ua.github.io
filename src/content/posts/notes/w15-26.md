## Mythos and Glasswing

Anthropic announced a [Claude Mythos Preview](https://www.anthropic.com/glasswing) and a program called Project Glasswing. The model sits above Opus and is restricted to security partners for now. The stated reason is that it finds software vulnerabilities too well to release openly. I worked on Ocular and Autofix at Qwiet AI. Ocular scored source-to-sink paths on code property graphs with a graph neural network. It was good and it was narrow. A general model that finds flaws better than a purpose-built system is a different thing. I believe the restriction is sincere. I also expect the capability to be table stakes within a year.
