The espionage disclosure is the story of the week. Everything else is a footnote.

## What happened

- OpenAI released [GPT-5.1](https://openai.com/index/gpt-5-1/) in Instant and Thinking variants. Better instruction following, adjustable reasoning. A solid update. Our eval shows small gains on structured output.
- Anthropic announced a [50 billion dollar investment](https://www.anthropic.com/news/anthropic-invests-50-billion-in-american-ai-infrastructure) in US data centers.
- Anthropic [disclosed](https://www.anthropic.com/news/disrupting-AI-espionage) that a state-backed group used Claude Code to run a largely automated intrusion campaign against around thirty organizations.
- Baidu unveiled [ERNIE 5.0](https://www.hpcwire.com/aiwire/2025/11/13/baidu-unveils-ernie-5-0-and-a-series-of-ai-applications-at-baidu-world-2025/).

## What I make of it

I worked on code security at Qwiet AI while I was at Developers Inc. Ocular found vulnerabilities by analyzing code property graphs. Autofix proposed repairs using a chain of LLM agents with a verifier in the loop. So the espionage report did not surprise me. An agent that can read a codebase and write exploits is the same agent that can read a codebase and fix them. The capability is symmetric. The intent is not.

What the report changes is the conversation with clients. Until now, "agent safety" in enterprise meetings meant hallucinations and data leaks. Now it also means an attacker running the same agent tooling we use, against us, at machine speed. The defenses are boring and known. Least privilege for every tool the agent can call. Audit logs that a human reads. Approval gates on anything that changes state. We already do this on the cloud operations agent we are building. This week I added it to the first slide of every client deck.

GPT-5.1 is good. It is not the point this week.
