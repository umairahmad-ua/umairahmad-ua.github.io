A short note this week. One feature, one model, one thing I got wrong.

## Artifacts that call connectors

Claude Code released a week of changes and the one I keep returning to is this. [Artifacts can now call MCP connectors](https://code.claude.com/docs/en/whats-new/2026-w29). A page you publish from a session can read live data through the same MCP servers the agent uses.

Here is why that matters for us. Every Scout demo used to be a screenshot of a dashboard. Then it became a static page. Now it can be a page that queries the client's BigQuery through a connector we already wrote for the agent. Same auth, same tool contract, same audit trail. The demo and the product start to share a spine.

The same release added `/fork` for branching a session and a screen-reader mode. One of my engineers uses a screen reader. This week the tool got better for her, not just for the release notes.
